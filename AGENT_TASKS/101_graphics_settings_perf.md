# Task 101: graphics settings, what each costs, what is missing, and where the time goes

Autonomous task (user afk, 10-minute reminder loop). Goal: (1) measure CPU/GPU cost of each graphics setting and of each planet feature
category in a valid forest walk; (2) decide which features need an on/off or quality option in the settings menu (`components/graphics_settings.gd`,
`ui/settings_menu.gd`) and add them, defaults right for plain Play, presets Low..Ultra sensible; (3) extensive perf debugging: find what to improve.

Rules: one game instance at a time; no focus stealing (override.cfg no_focus, `--screen 1`, timeouts); no commits; walk must be on land
(memory forest-walk-must-stand-on-land); never touch the user's Chrome tab.

## Tools
- `PLANET_PRESET=low|medium|high|ultra` and (new) `PLANET_GFX=key=value,key=value` (single settings on top, this run only; `graphics_settings.gd`).
- Sweep: scratchpad `sweep.sh OUT < configs` (lines `label|PRESET|GFX|EXTRA lab args`), forest walk 20 s, parses FOREST_WALK fps/gpu/cpu lines.
- Lab flags `--hide=trees|plants|ground|water`, `--no-shadow`, `--no-clouds`, env `PLANET_NO_*` (grass, turf, gravel, limbs, sway, undergrowth, plant colliders...).

## Plan
1. Preset sweep (low/medium/high/ultra). 2. From High: one option off/on at a time (ssao, ssil, glow, sdfgi, volumetric_fog, reflections, cloud_shadows, cloud_quality, shadow_quality, aa, upscaler, ground_detail, decals, particles, occlusion_culling, render_scale).
3. Feature categories (trees, plants/grass, ground, water, clouds, fauna, weather) cost by `--hide`/env. 4. Candidate new options (tree draw distance, grass density, plant/tree detail, shadow distance for trees, physics colliders on plants...). 5. Profile CPU (scripts 79 ms/frame with trees!) and GPU hot spots, fix what is cheap.

- GPU ms on High (base 45.9; reliable): tree distance 1.5 km + bend off -14.9 | shadows off -9.3 | TAA->SMAA/FXAA -8.0 | ground detail 1 -7.3 (also -11 M triangles) | SSAO off -4.2 | render scale 0.8 -4.2 | rest within noise (clouds, glow, fog, reflections, decals, particles, bark parallax -1, soft shadow filter, sun glow/shafts, turf/grass, occlusion culling).
- CPU: planet script nodes ~3 ms total; the voxel ground = 3 generator threads at 100% (+5 ms main thread, ~1100 draw calls), early-play dip while it settles; fewer samples per block / faster exp did not help; plant bend = frame spikes (p95), not average.

- Tools: PLANET_PRESET / PLANET_GFX, LAB_LEAN, --stand, --census, --perf-overlay, --loading-shot, frame_timer.h (PLANET_TIMING), sampling profiler (scratchpad), memory note `perf-measurement-lessons`.
- Decisions left to the user: High with 3 km trees (20-30 fps) vs 1.5 km; High with TAA (stable foliage) vs SMAA (-8 ms GPU); ground detail Fine vs Normal on High (-7 ms); GPU bake of the height noise (the load is now plants-bound, 18 s: not worth it for load time); caves/digging off in Low.
- RESOLVED (tick 77): the High "regression" (20 fps, 45 ms GPU) did not reproduce after tick 76: High lean now 30-34 fps, GPU 24 ms, with every switch (tect cache, 3D cover, ready rule, plant threads). It was almost certainly another GPU load on this machine during those runs (Low/Medium are CPU bound and did not move): check `nvidia-smi` for other GPU users before trusting a High number.

### Tick 96: trees popping while flying (found), lake water over sand (not found yet)
- Pop log (`--pop-log` in planet_lab): trees are drawn in small nodes (1-4 trees), each going in/out of its visibility range on its own (about 2 a frame while flying); FADE_SELF was set on all of them. Root cause: the engine fades through the shader's ALPHA (it starts as the fade), and flora_wind.gdshader writes ALPHA itself for the leaf cards (`ALPHA = card_alpha`), so the fade was thrown away: the leaves popped at the end of the range while only the plain parts faded (the engine forces a fading surface into the alpha pass). Fix in flora_wind.gdshader: `range_fade = ALPHA` first, a screen-noise dither discard when it is under 1, and `ALPHA = 1` with the scissor for the non-card parts, so no blending. Screenshot: leaves dither near the end of the range; fly2_30m.mp4 recorded with it. Not yet compared by eye frame by frame.
